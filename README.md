# 🎯 เว็บจดโพยตัวเลข & กระดานตัดเลข (Lottery Number Board)

Web Application สำหรับจดโพย**เฉพาะตัวเลข** พร้อมระบุ**ชื่อเว็ปกำกับ** และ**ชื่อหวย** และจัดแสดงผลเป็นกระดานตัดเลขสไตล์ตาราง Excel พร้อมระบบบันทึกข้อมูลคลาวด์ผ่าน **Supabase**

---

## 🌟 ฟังก์ชันการใช้งาน

### 1. 🏷️ ช่องเลือกชื่อหวย (สามารถเพิ่มและลบได้ตามต้องการ)
- บริเวณแถบด้านบน ตรงช่อง **"ชื่อหวย"**:
  - มีปุ่ม **`[ เพิ่ม/ลบ ]`** อยู่ข้างๆ กล่องเลือกหวย
  - คลิกเพื่อเปิดหน้าต่าง **จัดการรายชื่อหวย**:
    - **➕ เพิ่มชื่อหวยใหม่**: พิมพ์ชื่อหวยที่ต้องการ เช่น `ฮานอยสตาร์`, `ลาวสตาร์`, `ดาวโจนส์` แล้วกด **"เพิ่ม"** (หรือกด Enter) ระบบจะเพิ่มเข้าลิสต์และเลือกใช้งานทันที
    - **🗑️ ลบชื่อหวย**: มีปุ่มถังขยะสีแดงข้างชื่อหวยแต่ละรายการ คลิกเพื่อลบชื่อหวยที่ไม่ต้องการใช้งานออกได้ทันที
    - **ปุ่ม "คืนค่าเริ่มต้น"**: หากต้องการรีเซ็ตรายชื่อหวยกลับสู่ค่ามาตรฐาน
  - รายชื่อหวยที่เพิ่ม/ลบ จะถูกบันทึกลงในระบบและเชื่อมต่อฐานข้อมูลคลาวด์อย่างถาวร

### 2. 📝 กล่องวางตัวเลข (จดโพย)
- **ชื่อหวย**: เลือกหวยที่ต้องการจากรายการที่สร้างไว้
- **ชื่อเว็ปกำกับ**: ระบุชื่อเว็ป เช่น `lotterich`, `chudjen`, `huaydee` หรือคลิกปุ่มเลือกเว็ปด่วน
- **ป้ายกำกับหัวตาราง (แถบเขียว)**: ระบุข้อความหัวตาราง เช่น `ตัดยอด 55` หรือ `1000/ตัว`
- **การแยกหมวดตัวเลข**:
  - `แยกอัตโนมัติ`: เลข 3 หลักจะถูกส่งเข้าตาราง **"3 บน"**, เลข 2 หลักจะถูกส่งเข้าตาราง **"2 บน"**
  - หรือเลือกเจาะจงเฉพาะหมวด (3 บน, 2 บน, 2 ล่าง, 3 โต๊ด)
- **กล่องวางตัวเลข**:
  - วางตัวเลขล้วนๆ ได้เลย ไม่ว่าจะคั่นด้วยการเคาะวรรค, เคาะขึ้นบรรทัดใหม่, ลูกน้ำ หรือก๊อปปี้มาจากไฟล์/Excel
  - มีแถบนับจำนวนตัวเลขอัตโนมัติแบบสดๆ (Live Counter)
- เมื่อกด **"✨ นำขึ้นกระดานตัดเลข"** ข้อมูลจะถูกจัดเข้ากระดานให้อัตโนมัติทันที

### 3. 📊 กระดานตัดเลข (แบบ Excel ในรูปภาพ)
- **หัวข้อกระดาน**: แสดงชื่อหวยเด่นชัด (เช่น ฮานอยพิเศษ)
- **จัดตารางสไตล์ Excel**:
  - แสดงตัวเลขเรียงแนวตั้ง 10 คอลัมน์ (หรือเลือก 6, 8, 12 ได้) จากบนลงล่าง
  - แต่ละตารางมีหัวตารางระบุ **ชื่อเว็ป** (เช่น `lotterich`) และ **แถบสีเขียว** (เช่น `ตัดยอด 55`)
  - แต่ละเว็ปจะแสดงตารางเคียงข้างกันเหมือนในภาพ Excel ต้นฉบับ
  - มุมล่างขวาของตารางมีตัวนับจำนวน **`count: 230`**
- **เครื่องมือในกระดาน**:
  - **ค้นหาตัวเลข**: พิมพ์เลขปุ๊บ ช่องนั้นจะกระพริบสีเหลืองเด่นชัดทันที
  - **คัดลอกลง Excel**: ก๊อปปี้ตารางไปกดวาง (`Ctrl+V`) ใน Microsoft Excel หรือ Google Sheets จะได้ตารางเหมือนเดิมทันที
  - **ลบเฉพาะเว็ป**: มีปุ่มถังขยะที่มุมล่างเพื่อลบเฉพาะตารางเว็ปนั้นได้
  - **ล้างกระดาน**: ล้างข้อมูลทั้งหมดเพื่อเริ่มงวดใหม่
  - **พิมพ์กระดาน (Print A4)**

## 🗄️ การเชื่อมต่อฐานข้อมูล Supabase (Cloud Database)

ระบบรองรับการเชื่อมต่อฐานข้อมูล PostgreSQL ผ่าน **Supabase** ฟรี เพื่อให้ข้อมูลตัวเลขที่กรอกและรายชื่อหวยไม่สูญหาย เปิดใช้งานจากอุปกรณ์ใดก็เห็นข้อมูลตรงกัน

### ขั้นตอนที่ 1: สร้างฐานข้อมูลบน Supabase
1. เข้าไปที่ [supabase.com](https://supabase.com) แล้วล็อกอิน / สร้างโปรเจกต์ใหม่ (ฟรี)
2. ไปที่เมนู **SQL Editor** ทางซ้ายมือ
3. เปิดไฟล์ `supabase_schema.sql` ในโปรเจกต์นี้ แล้วคัดลอกโค้ด SQL ทั้งหมดไปวางใน SQL Editor แล้วกด **Run**
4. ระบบจะสร้างตาราง `lottery_batches` และ `lottery_names` พร้อมเปิดสิทธิ์ RLS ให้เรียบร้อย

### ขั้นตอนที่ 2: นำ Keys มาเชื่อมต่อ
ไปที่ Supabase -> **Project Settings** -> **API**:
- คัดลอก **Project URL**
- คัดลอก **anon / public key**

#### วิธีใส่ในหน้าเว็บตรงๆ:
- กดปุ่ม **`Supabase`** ด้านบนขวาของหน้าเว็บ
- วาง Project URL และ Anon Key แล้วกด **"บันทึก & เชื่อมต่อ"**

#### วิธีใส่ใน Streamlit Cloud (แนะนำเมื่อ Deploy):
- ไปที่หน้า Dashboard ของแอพใน Streamlit Cloud
- ไปที่ **Settings** -> **Secrets**
- เพิ่มค่าตามนี้:
```toml
SUPABASE_URL = "https://your-project.supabase.co"
SUPABASE_ANON_KEY = "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9..."
```
- แอพจะเชื่อมต่อกับ Supabase ให้โดยอัตโนมัติทันทีที่เปิดเว็บ!

## 🚀 วิธีเปิดใช้งาน (Run & Deploy)

### 1. เปิดออนไลน์ผ่าน Streamlit Community Cloud (ฟรี 100%)
1. เข้าไปที่ [share.streamlit.io](https://share.streamlit.io) แล้วล็อกอินด้วย GitHub
2. กดปุ่ม **"Create app"**
3. เลือก Repository: `Sukol1996/PoiHuay`
4. Branch: `main`
5. Main file path: `app.py`
6. (ถ้าต้องการต่อ Supabase) ใส่ค่าในช่อง **Advanced settings -> Secrets**
7. กด **"Deploy!"** ระบบจะสร้างลิงก์เว็บไซต์ออนไลน์ให้ทันที (เช่น `https://poihuay.streamlit.app`)
